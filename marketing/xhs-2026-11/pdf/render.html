2去官方平台拿一个 API Key软件不收费，只有这一步要花钱
1
打开 platform.deepseek.com 并登录
手机号或邮箱登录，没有账号先注册，一分钟。
2
左侧「API keys」→「创建 API key」→ 复制
随便起个名字（比如 ds-echo），弹窗里那串 sk- 开头的就是 Key。
3
左侧「充值」，充 10 块够用很久
按用量扣费，没有月费、套餐、会员，不用就不花钱；新号可能自带赠送额度。
只显示这一次：那个弹窗一关，Key 就再也看不到了（不是丢了，是官方不再展示）。没复制到就删掉重建，免费。
3把 Key 填进 App
✓
首次打开就是连接向导
粘贴 Key → 点「验证并连接」→ 屏幕上出现余额数字，就说明连上了。 Key 只存在你手机本机的加密区，不经过任何服务器。
4导入官方聊天记录，把旧对话接回来这一步才是重点
A
先在官方导出
DeepSeek 官方 App 或网页版里找到「导出对话记录」，会得到一个 ZIP 文件，存到手机。
B
App 里：设置 → 数据管理 → 导入历史对话
上传那个 ZIP。导入前会先给你预览"新增几条、跳过几条"，确认后才写入 — 不覆盖你原有的记录，以后也能再导出回官方格式。
5卡住了看这里
你会看到 原因 怎么处理
API Key 无效 复制少了字符，或复制成了别的东西 回平台删掉重建，整串重新复制，别手打
余额不足，请先充值 还没充钱，或充完没同步 官方充值页确认到账，App 里点一次「刷新」
付款时要求实名 支付渠道的风控要求 按页面走一次，之后不再要
找不到导出入口 版本不同，入口位置不一样 改用网页版导出，再把 ZIP 传手机
隐私：没有后端、没有统计 SDK、不收集任何数据；聊天记录和附件只存在你手机上。
