API Key

比注册一个账号，只多一步

App 首屏
就是这三步
只显示这一次
1

去官方平台建一个 Key

打开 platform.deepseek.com 登录，左侧「API keys」→「创建 API key」→ 随便起个名字，弹窗里那串 sk- 开头就是了。

API keys → 创建 API key → sk-•••••••• → 复制
2

充点钱，按量计费

左侧「充值」，充 10 块。没有月费、套餐、会员；不用不花，新号还可能带赠送额度。

充值 → 10 元 → 扫码付款 → 用多少扣多少
3

粘进 App，点「验证并连接」

打开 DS Echo，首屏就是这个向导。粘好点连接，它会自动查一次余额 —— 看到余额数字就说明成功了，不用你猜。

粘贴 sk-•••• → 验证并连接 → ✓ 余额已显示
