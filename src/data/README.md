# 打赏名单（手动维护）

这个 App 没有后端，**不可能自动知道谁打了赏**，所以名单要自己填。

编辑 `donations.json`，每条格式：

```json
{ "name": "小林", "amount": 6.66, "message": "帮了大忙，谢谢", "date": "2026-11-18" }
```

- `name` 留空或写 "匿名" 都会显示成「匿名」
- `amount` 是数字，用于**按金额从大到小排序**（显示时自动加 `¥` 和两位小数）
- `message` 可省略
- `date` 只用于区分同名同额的条目，不显示

填完重新构建即可。默认给的几条是**示例**，发布前请清空，否则看起来像在编造捐赠记录。
