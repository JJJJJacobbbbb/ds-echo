# 打赏名单怎么维护

## 最短路径（不用发版）

1. 打开 <https://github.com/JJJJJacobbbbb/ds-echo/blob/main/donations.json>
2. 点右上角铅笔图标（Edit）
3. 在 `items` 里加一条，并顺手改 `updatedAt`：

```json
{
  "updatedAt": "2026-11-20",
  "items": [
    { "name": "小林", "amount": 6.66 },
    { "name": "", "amount": 66.66 }
  ]
}
```

4. 页面底部 **Commit changes**

**生效时间**：用户下次打开打赏弹窗时拉取。jsDelivr 有 CDN 缓存，通常几分钟到几小时。

## 字段

| 字段 | 说明 |
|---|---|
| `updatedAt` | 名单最后更新时间，显示在"打赏名单"右侧（手动写，不是自动的） |
| `items[].name` | 昵称；留空则显示「匿名」 |
| `items[].amount` | 数字，**排序按它从大到小**，显示时自动加 `¥` 和两位小数 |

只有名称和金额，没有留言——弹窗里只显示这两列。

## 规矩（建议自己守住）

- **先问再写**：对方花钱支持你，名字公开前最好确认一句
- **不编造**：没有的记录不要写，这比空名单更糟
- **金额别改**：人家给多少就是多少

## 为什么名单要手动维护

本 App 没有后端、也不收集用户数据，拿不到"谁付了钱"（微信/支付宝个人收款也没有回调通知）。
只能你看到账后手动记一笔。

## 兜底

App 内置了一份名单（`src/data/donations.json`），远端拉不到时显示它，
所以即使 GitHub 完全打不开，弹窗也不会空着。
